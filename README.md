# algae

Algae is a deep AI agent, with a Discord integration.

## Installation

```
$ gh repo clone poundde/algae
$ cd algae
$ pip install -e . -U
```

### Updating

```
$ cd algae
$ git pull
```

## Usage

```
$ algae create my-bot
$ cd my-bot
$ # Edit the `config.yaml` and `config.md.j2` files in a text editor.
$ algae run
```
